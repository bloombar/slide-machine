How to write each type:
- "single_choice": give 3-4 "choices" with exactly ONE correct; set "correctIndex" to the zero-based position of the correct choice. No other answer fields.
- "multiple_choice": give 3-5 "choices" with ONE OR MORE correct; set "correctIndexes" to the zero-based positions of all correct choices. No "correctIndex".
- "short_text": a question answerable in a few words; set "correctAnswers" to the accepted answer(s). No "choices".
- "long_text": an open-ended question answered in a paragraph; no "choices" and no answer key.
